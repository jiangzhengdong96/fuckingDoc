### Java 线程知识点清单

###### 内容概述

本文件记录 线程基础、创建方式、线程状态、线程安全、线程协作、常见坑、关联面试题 等一级栏目知识点。

###### 使用场景

- Android 中网络请求、文件读写、数据库操作和图片处理不能阻塞主线程。
- 线程池适合管理后台任务，避免频繁创建线程。
- 线程安全知识用于处理共享状态、缓存、单例和多任务并发问题。
- 理解线程状态和协作有助于排查 ANR、死锁和任务卡住问题。

###### 常见坑


- 直接调用 `run()` 不会启动新线程。
- `volatile` 不能保证复合操作原子性。
- `wait()` 必须在同步代码中使用。
- Android 子线程不能直接更新 UI。
