### Java Lambda / Stream / Optional 知识点清单

###### 内容概述

本文件记录 java基础1 中拆分出来的 Lambda、Stream、Optional 专题入口，后续继续展开具体知识点。

###### 使用场景

- Lambda 常用于回调、监听器、集合遍历和异步任务结果处理。
- Stream 适合对列表数据做过滤、转换、分组和聚合，但 Android 中要注意可读性和性能。
- Optional 可用于表达可能为空的返回值，但 Android 项目里仍要结合团队空值规范使用。
