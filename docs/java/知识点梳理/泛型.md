### Java 泛型知识点清单

###### 内容概述

本文件记录 泛型基础、泛型使用位置、通配符、类型擦除、常见限制、关联面试题 等一级栏目知识点。

###### 使用场景

- 泛型常用于 `List<T>`、`Map<K, V>`、Adapter、Repository、BaseResponse 等通用结构。
- Retrofit、Room、Json 解析和事件分发中经常会遇到泛型类型传递。
- 通配符和上下界用于设计可复用 API，减少强制类型转换和类型错误。
- 类型擦除有助于理解运行时泛型判断、反射和序列化解析的限制。

###### 类型擦除


- 泛型主要在编译期生效。
- 运行期类型信息会被擦除。
- 编译器插入必要的类型转换。
- 运行期不能直接判断 `List<String>`。


###### 常见限制


- 不能直接 `new T()`。
- 泛型数组创建受限制。
- `List<String>` 不是 `List<Object>` 的子类。
- 不能直接 `obj instanceof List<String>`。
