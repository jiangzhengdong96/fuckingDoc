## 集合体系

- `Collection`。
- `List`。
- `Set`。
- `Queue`。
- `Map`。
- 迭代器 `Iterator`。
- 增强 for 循环。

## List

- `ArrayList`。
- `LinkedList`。
- 有序。
- 可重复。
- 按索引访问。
- 扩容机制。

## Set

- `HashSet`。
- `LinkedHashSet`。
- `TreeSet`。
- 元素不重复。
- 依赖 `equals` / `hashCode` 或排序规则。

## Map

- `HashMap`。
- `LinkedHashMap`。
- `TreeMap`。
- `ConcurrentHashMap`。
- key-value。
- hash 冲突。
- 扩容。
- 树化。

## Queue

- `Queue`。
- `Deque`。
- `ArrayDeque`。
- `PriorityQueue`。
- FIFO。
- 优先级队列。

## 常见坑

- 遍历时直接删除元素可能触发 `ConcurrentModificationException`。
- 自定义对象作为 key 时要重写 `equals` 和 `hashCode`。
- `HashMap` 不是线程安全的。
- `ArrayList` 随机访问快，但频繁头部插入删除不适合。
