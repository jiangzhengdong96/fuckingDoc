###### 常见坑

###### 常见坑的各个点

- 遍历时直接删除元素可能触发 `ConcurrentModificationException`。
- 自定义对象作为 key 时要重写 `equals` 和 `hashCode`。
- `HashMap` 不是线程安全的。
- `ArrayList` 随机访问快，但频繁头部插入删除不适合。
