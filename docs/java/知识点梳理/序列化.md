### Java 序列化知识点清单

###### 内容概述

本文件记录 java基础1 中拆分出来的序列化专题入口，后续继续展开具体知识点。

###### 使用场景

- Android 页面跳转、进程间传递和本地缓存会涉及对象序列化。
- `Parcelable` 更常用于 Android 组件间传递数据。
- `Serializable` 使用简单，但要关注性能、兼容性和 `serialVersionUID`。
- 网络 JSON 转对象属于数据编解码场景，和 Java 原生序列化不是一回事。
