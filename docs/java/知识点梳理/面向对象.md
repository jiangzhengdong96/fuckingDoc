## 三大特性

- 封装。
- 继承。
- 多态。

## 继承

- 父类。
- 子类。
- 非 private 成员。
- 构造方法不被继承。
- `this`。
- `super`。
- 耦合性。

## 重载和重写

- 重载：方法名相同，参数列表不同。
- 重写：子类重新实现父类方法。
- 重载不能只靠返回值区分。
- 重写访问权限不能更小。
- 重写返回值类型和异常有约束。

## 多态

- 继承。
- 重写。
- 父类引用指向子类对象。
- 编译期看父类。
- 运行期执行子类实现。
- 虚方法调用。

## 接口和抽象类

- 抽象类偏模板和代码复用。
- 接口偏行为契约和解耦。
- 类只能单继承。
- 类可以实现多个接口。
- 接口可多继承接口。
- JDK8+ 接口默认方法。

## 常见坑

- static 方法不能被重写，只能隐藏。
- 构造方法不能被重写。
- 字段没有运行期多态。
- 继承不是复用的唯一方式，组合也常用。
