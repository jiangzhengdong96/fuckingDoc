###### Java 异常体系是什么

答案：

**简答：** Java 异常体系根类是 `Throwable`，下面主要分为 `Error` 和 `Exception`。

**展开回答：** `Exception` 又可以分为运行时异常和编译时异常。

**易错点：** `RuntimeException` 编译期不强制捕获。

**关联知识点：** [Java 异常](../知识点梳理/异常.md)

###### Exception 和 Error 有什么区别

答案：

**简答：** `Exception` 通常表示程序可以处理的问题，`Error` 通常表示 JVM 或系统级严重问题。

**展开回答：** 业务代码通常处理 Exception，不应该试图常规捕获和恢复 Error。

**易错点：** `OutOfMemoryError` 属于 Error。

**关联知识点：** [Java 异常](../知识点梳理/异常.md)

###### throw 和 throws 有什么区别

答案：

**简答：** `throw` 抛出具体异常对象，`throws` 声明方法可能抛出异常。

**展开回答：** `throw` 写在方法体中；`throws` 写在方法声明上。

**易错点：** `throws` 不处理异常，只是把异常处理责任交给调用方。

**关联知识点：** [Java 异常](../知识点梳理/异常.md)

###### finally 中 return 会发生什么

答案：

**简答：** finally 中的 return 可能覆盖 try/catch 中的返回值。

**展开回答：** finally 中 return 还可能吞掉前面抛出的异常，因此不建议在 finally 中 return。

**易错点：** finally 中抛出的异常也会覆盖前面的异常。

**关联知识点：** [Java 异常](../知识点梳理/异常.md)

###### try-with-resources 解决什么问题

答案：

**简答：** 自动关闭资源。

**展开回答：** 实现 `AutoCloseable` 的资源可以放入 try-with-resources 中，语句结束后自动调用 `close()`。

**易错点：** 它主要解决资源释放问题，不是异常消失。

**关联知识点：** [Java 异常](../知识点梳理/异常.md)
