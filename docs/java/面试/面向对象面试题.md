###### 封装是什么

答案：

**简答：** 封装是把对象内部状态和实现细节隐藏起来，只暴露受控的访问方式。

**展开回答：** 好的封装不是单纯隐藏字段，而是通过方法维护对象状态的合法性，把数据和行为组织在同一个对象中。

**易错点：** 字段改成 private 只是封装的基础，不代表设计已经合理。

**关联知识点：** [面向对象 - 封装](../知识点梳理/面向对象.md#封装)

###### getter 和 setter 就等于封装吗

答案：

**简答：** 不等于。

**展开回答：** getter/setter 只是访问形式。如果 setter 只是无条件暴露所有字段，本质上仍然可能破坏封装。封装更关注对象对外提供什么行为、如何保证状态合法。

**易错点：** 自动生成 getter/setter 不等于完成了面向对象设计。

**关联知识点：** [面向对象 - 封装](../知识点梳理/面向对象.md#封装)

###### 继承解决什么问题

答案：

**简答：** 继承用于复用父类可访问成员，建立 is-a 层级，并支持多态。

**展开回答：** 子类可以在父类基础上扩展能力，也可以重写父类方法以提供子类自己的行为。

**易错点：** 继承不是单纯为了少写代码，滥用继承会让子类依赖父类实现细节。

**关联知识点：** [面向对象 - 继承](../知识点梳理/面向对象.md#继承)

###### 为什么很多场景建议优先使用组合而不是继承

答案：

**简答：** 因为组合的耦合更低，替换和扩展更灵活。

**展开回答：** 继承会让子类依赖父类的实现和层级结构，父类改动可能影响所有子类。组合通过持有对象来复用能力，更适合行为拼装和模块解耦。

**易错点：** 不是完全不用继承，而是不要把“复用代码”作为继承的唯一理由。

**关联知识点：** [面向对象 - 继承](../知识点梳理/面向对象.md#继承)

###### this 和 super 分别表示什么

答案：

**简答：** `this` 表示当前对象引用，`super` 表示以直接父类视角访问父类成员。

**展开回答：** `this()` 可以调用本类其他构造方法，`super()` 可以调用父类构造方法；二者如果用于构造方法调用，都必须放在构造方法第一句。

**易错点：** `this()` 和 `super()` 不能同时作为构造方法第一句出现。

**关联知识点：** [面向对象 - 继承](../知识点梳理/面向对象.md#继承)

###### super 是不是指向一个独立的父类对象

答案：

**简答：** 不是。

**展开回答：** 创建子类对象时，不会额外创建一个独立父类对象。`super` 只是从当前子类对象中，以父类视角访问父类成员或构造流程。

**易错点：** 子类对象内部包含父类部分的状态，但这不等于存在两个对象。

**关联知识点：** [面向对象 - 继承](../知识点梳理/面向对象.md#继承)

###### 子类会继承父类构造方法吗

答案：

**简答：** 不会。

**展开回答：** 构造方法不能被继承，也不能被重写。子类构造时会先调用父类构造方法，默认调用父类无参构造；如果父类没有无参构造，子类需要显式调用合适的 `super(...)`。

**易错点：** “调用父类构造方法”不等于“继承父类构造方法”。

**关联知识点：** [面向对象 - 继承](../知识点梳理/面向对象.md#继承)

###### 子类对象初始化顺序是什么

答案：

**简答：** 先父类静态，再子类静态；先父类实例和构造，再子类实例和构造。

**展开回答：** 常见顺序是：父类静态变量/静态代码块，子类静态变量/静态代码块，父类实例变量/实例代码块，父类构造器，子类实例变量/实例代码块，子类构造器。

**易错点：** 静态部分只在类初始化时执行一次，实例部分每次创建对象都会执行。

**关联知识点：** [面向对象 - 继承](../知识点梳理/面向对象.md#继承)

###### 重载和重写有什么区别

答案：

**简答：** 重载是同名方法参数列表不同，编译期确定；重写是子类重新实现父类实例方法，运行期动态分派。

**展开回答：** 重载可以发生在同一个类或子类中；重写要求方法名和参数列表一致，通常用于实现多态。

**易错点：** 不能只靠返回值不同构成重载。

**关联知识点：** [面向对象 - 重载](../知识点梳理/面向对象.md#重载)

###### 方法重写有哪些限制

答案：

**简答：** 子类重写方法时，方法名和参数列表必须一致，访问权限不能更小，返回值类型和异常范围不能更宽。

**展开回答：** 被 `private`、`final` 修饰的方法不能被重写；`static` 方法不参与普通重写；构造方法不能被重写。

**易错点：** 子类可以缩小返回值类型和检查异常范围，但不能扩大。

**关联知识点：** [面向对象 - 重写](../知识点梳理/面向对象.md#重写)

###### static 方法能被重写吗

答案：

**简答：** 不能。

**展开回答：** static 方法属于类，不参与运行期多态。子类声明同签名 static 方法属于隐藏，不是重写。

**易错点：** “能再次声明”不等于“重写”。

**关联知识点：** [面向对象 - 重写](../知识点梳理/面向对象.md#重写)

###### 多态的必要条件是什么

答案：

**简答：** 继承或接口实现、方法重写、父类或接口引用指向子类对象。

**展开回答：** 编译期看引用类型，运行期根据对象真实类型执行对应方法实现。多态可以让代码面向抽象编程，降低耦合。

**易错点：** `private`、`static`、`final` 方法以及构造方法不按普通虚方法动态分派。

**关联知识点：** [面向对象 - 多态](../知识点梳理/面向对象.md#多态)

###### 字段有没有多态

答案：

**简答：** 字段没有运行期多态。

**展开回答：** 字段访问看引用类型，方法调用才看运行时对象类型。父类引用指向子类对象时，访问同名字段按父类引用类型解析，调用重写方法按子类真实类型分派。

**易错点：** 不要把字段隐藏和方法重写混在一起。

**关联知识点：** [面向对象 - 多态](../知识点梳理/面向对象.md#多态)

###### 接口和抽象类有什么区别

答案：

**简答：** 抽象类偏一类事物的共性模板和代码复用，接口偏一组行为规范和解耦。

**展开回答：** 类只能继承一个抽象类，但可以实现多个接口。抽象类可以有构造方法、成员变量和普通方法；接口变量默认是 `public static final`，接口方法规则随 JDK 版本有所变化。

**易错点：** JDK 8 后接口可以有默认方法和静态方法，JDK 9 后接口可以有私有方法。

**关联知识点：** [面向对象 - 接口和抽象类](../知识点梳理/面向对象.md#接口和抽象类)

###### Java 为什么不支持类多继承

答案：

**简答：** 为了避免多个父类带来的状态和实现冲突。

**展开回答：** 如果一个类同时继承多个父类，字段、构造过程和同名方法都可能产生复杂冲突。Java 选择类单继承，同时用接口多实现来表达多种能力。

**易错点：** 接口可以多继承接口，类也可以多实现接口，但类不能多继承类。

**关联知识点：** [面向对象 - 接口和抽象类](../知识点梳理/面向对象.md#接口和抽象类)

###### JDK 8 以后接口有哪些变化

答案：

**简答：** JDK 8 接口支持默认方法和静态方法，JDK 9 接口支持私有方法。

**展开回答：** 默认方法用于在接口升级时提供默认实现，避免所有实现类都必须立刻修改；静态方法属于接口本身；私有方法可以复用接口内部默认方法的公共逻辑。

**易错点：** 接口静态方法只能通过接口名调用，不能通过实现类继承调用。

**关联知识点：** [面向对象 - 接口和抽象类](../知识点梳理/面向对象.md#接口和抽象类)
