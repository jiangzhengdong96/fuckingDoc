###### 重载和重写有什么区别

答案：

**简答：** 重载发生在同一个类或继承关系中，参数列表不同；重写发生在子类对父类方法的重新实现。

**展开回答：** 重载是编译期根据参数选择方法；重写是运行期多态的基础。

**易错点：** 不能仅靠返回值区分重载。

**关联知识点：** [Java 面向对象](../知识点梳理/面向对象.md)

###### 接口和抽象类有什么区别

答案：

**简答：** 抽象类偏模板和代码复用，接口偏行为契约和解耦。

**展开回答：** 类只能单继承抽象类，但可以实现多个接口。接口适合定义能力，抽象类适合沉淀共性实现。

**易错点：** JDK8 后接口也可以有默认方法和静态方法。

**关联知识点：** [Java 面向对象](../知识点梳理/面向对象.md)

###### 多态的必要条件是什么

答案：

**简答：** 继承、重写、父类引用指向子类对象。

**展开回答：** 编译期看父类类型，运行期执行子类实现。

**易错点：** 字段没有运行期多态，方法才有动态分派。

**关联知识点：** [Java 面向对象](../知识点梳理/面向对象.md)

###### static 方法能被重写吗

答案：

**简答：** 不能。

**展开回答：** static 方法属于类，不参与运行期多态；子类定义同签名 static 方法属于隐藏。

**易错点：** “能再次声明”不等于“重写”。

**关联知识点：** [Java 面向对象](../知识点梳理/面向对象.md)

###### Java 为什么不支持类多继承

答案：

**简答：** 为了避免多继承带来的复杂性和冲突。

**展开回答：** Java 通过接口多实现来获得多继承的能力表达，同时避免多个父类状态和实现冲突。

**易错点：** 接口可以多继承接口，类不能多继承类。

**关联知识点：** [Java 面向对象](../知识点梳理/面向对象.md)
