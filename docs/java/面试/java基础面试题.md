###### Java 为什么大小写敏感

答案：

**简答：** Java 区分大小写，`Hello` 和 `hello` 是两个不同标识符。

**展开回答：** Java 的类名、变量名、方法名都属于标识符，编译器会按字符精确识别。大小写不同会被视为不同名字。

**易错点：** 类名和源文件名也要匹配 public 类名的大小写。

**关联知识点：** [基础语法和编码规范](../知识点梳理/java基础.md#基础语法和编码规范)

###### Java 有哪些数据类型

答案：

**简答：** Java 数据类型分为基本数据类型和引用数据类型。

**展开回答：** 基本数据类型包括 `byte`、`short`、`int`、`long`、`float`、`double`、`char`、`boolean`。引用数据类型包括字符串、数组、自定义类和 Java 自带类等。

**易错点：** `String` 不是基本数据类型。

**关联知识点：** [数据类型](../知识点梳理/java基础.md#数据类型)

###### Java 是值传递还是引用传递

答案：

**简答：** Java 只有值传递。

**展开回答：** 基本类型传递的是值的拷贝；对象作为参数时，传递的是对象引用的拷贝。方法内部可以通过引用修改对象状态，但不能改变调用方变量保存的引用地址。

**易错点：** “对象能被修改”不等于“Java 是引用传递”。

**关联知识点：** [拷贝和参数传递](../知识点梳理/java基础.md#拷贝和参数传递)

###### final 可以修饰什么

答案：

**简答：** `final` 可以修饰类、方法、变量。

**展开回答：** final 类不能被继承；final 方法不能被重写；final 变量赋值后不能重新赋值。

**易错点：** final 修饰引用变量时，引用地址不能变，但对象内部状态是否能变取决于对象本身。

**关联知识点：** [修饰符](../知识点梳理/java基础.md#修饰符)

###### static 变量和实例变量有什么区别

答案：

**简答：** static 变量属于类，实例变量属于对象。

**展开回答：** 一个类的 static 变量通常只有一份，所有对象共享；实例变量在每个对象中各自保存一份。

**易错点：** static 变量长期持有大对象引用可能造成内存问题。

**关联知识点：** [变量](../知识点梳理/java基础.md#变量)

###### 局部变量和成员变量有什么区别

答案：

**简答：** 局部变量定义在方法或代码块中，成员变量定义在类中、方法体外。

**展开回答：** 局部变量没有默认值，使用前必须初始化；成员变量有默认值，随对象创建而存在。

**易错点：** 访问修饰符不能修饰局部变量。

**关联知识点：** [变量](../知识点梳理/java基础.md#变量)
