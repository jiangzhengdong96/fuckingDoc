<a id="android-tv-播放器怎么选型"></a>
###### Android TV 播放器怎么选型

答案：

**简答：** 新项目通常优先考虑 Media3/ExoPlayer，特殊格式、DRM、厂商硬解或业务强定制再评估厂商 SDK 或自研方案。

**展开回答：** Media3/ExoPlayer 支持能力完整，扩展性强，适合点播、直播、字幕、轨道选择等常见场景。系统 MediaPlayer API 简单但扩展能力较弱。选型要看格式、直播/点播、清晰度、字幕、DRM、缓存、错误重试、埋点和设备兼容。

**易错点：** 播放器选型不能只看 demo 能不能播放，要看目标设备矩阵和业务能力。

**关联知识点：** [播放器选型](../知识点梳理/TV媒体播放.md#播放器选型)

<a id="播放页遥控器按键怎么设计"></a>
###### 播放页遥控器按键怎么设计

答案：

**简答：** 要定义确认、返回、上下左右、播放暂停、快进快退在控制层显示和隐藏两种状态下的行为。

**展开回答：** 常见设计是确认键显示控制层或触发当前焦点按钮，返回键先隐藏控制层再退出页面，左右键在控制层显示时切换按钮，在隐藏时可做快进快退。播放暂停键直接切换状态。所有行为要统一，避免有些按键无反馈。

**易错点：** 控制层隐藏时按方向键无响应，会让用户以为应用卡住。

**关联知识点：** [遥控器控制](../知识点梳理/TV媒体播放.md#遥控器控制)

<a id="播放页焦点层级怎么处理"></a>
###### 播放页焦点层级怎么处理

答案：

**简答：** 按错误页、弹窗/面板、控制层、视频根容器的优先级管理焦点。

**展开回答：** 错误页显示时，重试按钮应获得焦点。清晰度、字幕、选集面板显示时，焦点进入面板当前项。控制层显示时，焦点进入播放暂停或上次焦点按钮。控制层隐藏后，焦点不要停在不可见按钮上，可以回到视频根容器或等待下次显示时恢复。

**易错点：** 不可见控制层里的按钮如果还持有焦点，遥控器表现会很怪。

**关联知识点：** [播放页焦点](../知识点梳理/TV媒体播放.md#播放页焦点)

<a id="什么是音频焦点"></a>
###### 什么是音频焦点

答案：

**简答：** 音频焦点是 Android 用来协调多个应用或系统声音播放权的机制。

**展开回答：** 视频播放前通常要请求音频焦点。失去焦点时，根据焦点丢失类型暂停、降低音量或停止播放。TV 上还要考虑系统语音助手、蓝牙音箱、HDMI 设备、系统提示音等情况。

**易错点：** 不处理音频焦点可能导致和其他应用抢声音，或者退到后台后还在播放。

**关联知识点：** [音频焦点](../知识点梳理/TV媒体播放.md#音频焦点)

<a id="播放错误怎么处理"></a>
###### 播放错误怎么处理

答案：

**简答：** 要区分错误类型，给用户可操作方案，同时记录足够日志用于排查。

**展开回答：** 播放错误可能来自网络、资源、格式、解码、DRM、服务器、超时等。错误页要提供重试、返回、切换清晰度等入口。日志要记录播放地址类型、清晰度、错误码、设备信息、网络状态和播放器状态。

**易错点：** 只显示错误码对用户没有帮助，只记录用户提示对开发排查也不够。

**关联知识点：** [错误处理](../知识点梳理/TV媒体播放.md#错误处理)
