###### 笔记内容

2、用 `dart create -t package command_runner` 创建共享包，在 lib 下通过 export 组织对外入口；普通 Dart 文件已经是 library，不必额外声明 library。调用方在 pubspec.yaml 声明依赖后，再 import 入口文件。

Pub workspace 用于多个 package 共享依赖解析：根 pubspec 的 workspace 列出成员路径，各成员声明 resolution: workspace，使用其他成员的包仍需声明 dependencies，且版本约束须匹配。package 不限于稳定第三方库；业务包、应用和工具也都是 package，可以加入 workspace 共同开发。

完整配置和例子见 [Dart 包、库与工作区详解](./Dart包库与工作区详解.md)。

3、=单纯的赋值， => 作用于方法、函数、回调体  
4、类的构造方法可以是必选参数和可选参数的，用{}、[]区分，{}为可选命名参数 []为可选位置参数， required一般指定对应命名参数必填  
5、..联级调用，在不创建新变量的前提下，对同一个对象连续调用多个方法或访问多个属性。最终返回的还是对象本身，有点像apply

6、避空运算符： ??=, 当该变量为空值时才为其赋值

另一次：

Dart语言是类型安全的：它采用静态类型检查的组合 以及[运行时检查](https://dart.dev/language/type-system#runtime-checks) 确保变量的值始终与该变量的静态类型一致。 虽然_类型_是必填的，但类型_注释_是可选的 因为类型[推断](https://dart.dev/language/type-system#type-inference)。  
子类中方法的返回类型必须与父类中方法的返回类型相同，或者为其子类型。

重写方法的参数必须具有与超类中相应参数相同的类型或超类型

[飞镖简介](https://dart.dev/language)
