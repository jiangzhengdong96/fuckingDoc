# 面试笔记维护

1. 读取 `docs/knowledge-rules.md`，查找主题原文和同模块已有面试笔记。
2. 去重后维护实际问题标题，采用“简答版 → 深入追问 → 关联知识点”；新文件使用 interview 模板。
3. 答案要能独立理解，说明成立条件。细节链接主题原文，避免复制整篇分析。
4. 结论纠正时修改已有答案和相关代码，不只追加新题；不确定结论交由 knowledge-review。
5. 同步主题中的面试问法，使用稳定的显式锚点。非面试主题及纯格式调整不扩展题目。
6. 执行 knowledge-check，说明同步了哪些问答。

完成条件：问题与答案对应、无重复矛盾、关联链接有效；不把写出答案当成用户已经掌握。
